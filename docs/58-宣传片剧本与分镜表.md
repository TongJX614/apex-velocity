## 一、为什么要重做：上一版的三处断裂

旧片（`极速巅峰_宣传片.mp4`，80s）用的是**旧 WebGL 网页版**的画面，且叙事存在硬伤：

| 问题 | 具体表现 | 本版对策 |
| --- | --- | --- |
| **画面不是这个游戏** | 光秃地面、低模山体、老式大仪表 HUD、旧版车库卡片 | 全部改用当前 Godot 版实机逐帧录制（真实树/建筑、PBR 路面、HDRI 天空、紧凑仪表卡） |
| **逻辑断裂** | 已经发车跑起来 → 又回车库看车 → 再看**没有车**的空赛道 → 直接跳结算 | 改成单向时间线：选车 → 选赛道 → 发车 → 八站征途 → 高潮 → 冲线 → 成绩 |
| **主体缺席** | 8 条赛道全是空赛道巡礼，像场景检查，不是赛车宣传片 | **每一个赛道镜头都必须有车**，且车与景观同框；用 6 种电影机位拍摄 |

## 二、叙事设计：一条不回头的线

**一句话**：一名车手从清晨出发，横穿八条主题赛道，天光由昼入夜，最终在霓虹雨夜冲线。

**隐形骨架是「光线时间线」**，它让 8 条原本并列的赛道变成有先后顺序的一段旅程，而不是随机拼盘：

```
正午碧海 → 雪线暖阳 → 黄昏金光 → 落日港湾 → 赤岩夕照
        → 火山暮色 → 冰湖蓝调 → 霓虹雨夜
   亮度、色温逐级下降；节奏、速度感逐级上升
```

**六幕结构**（每幕只解决一件事，幕与幕之间不回头）：

| 幕 | 时间 | 叙事任务 | 观众得到的信息 |
| --- | --- | --- | --- |
| 0 品牌 | 00:00–00:03 | 亮明身份 | 这是《极速巅峰》 |
| 1 整装 | 00:03–00:09 | 建立前提 | 有 45 台车、8 条赛道可以选 |
| 2 发车 | 00:09–00:15 | 故事开始 | 3-2-1-GO，比赛真的开始了 |
| 3 征途 | 00:15–01:03 | 展示内容 | 八种地貌、八种光线、不同座驾 |
| 4 极限 | 01:03–01:13 | 情绪峰值 | 漂移 / 氮气 / 缠斗 / 座舱视角 |
| 5 冲线 | 01:13–01:19 | 收束闭环 | 跑完有成绩、有纪录 |
| 6 品牌 | 01:19–01:24 | 留下记忆点 | LOGO + 卖点 + Slogan |

**逻辑校验**：座驾展示放在发车**之前**（准备阶段），赛道巡礼全部**在比赛中**（车始终在跑），结算只在冲线**之后**出现。全片没有一次时间倒流。

## 三、镜头语言规范

1. **画面来源**：Godot Movie Maker 固定 30fps 逐帧录制当前版本真实渲染，游戏内自动驾驶沿赛道行驶。禁用旧版素材、AI 生成图、静态图伪装视频。
2. **机位库**（拍摄参数 `--trailer-shot`）：

| 机位 | 描述 | 用途 |
| --- | --- | --- |
| `hero` | 车侧后 8.5m、侧偏 5m、高 1.7m 的低 3/4 跟拍 | 车身 + 前方赛道，主镜头 |
| `lead` | 车前 24m、高 1.25m 的迎面低机位 | 车头朝镜头，背景流动，冲击力最强 |
| `side` | 车侧 11m、高 2.1m 的平行跟拍 | 展示车侧线条与横向景观 |
| `aerial` | 车后 26m、高 20m 俯瞰 | 展示赛道线形与地貌全景 |
| `chase` | 车后 8m、高 2.6m 贴地追尾 | 速度感、长直道 |
| `wheel` | 车侧 3.2m、高 0.55m 贴地 | 轮组 / 路肩特写，快切用 |

3. **选景原则**：优先「车在前、景在后」的构图；避开起跑区重复的龙门架与维修楼；用 `--shot-dist` 把车放到各赛道景观最好的赛段；远景要有天空/山体/楼群层次，不要只有沥青。
4. **HUD**：赛道与风景镜头隐藏 HUD（`--trailer-hud=0`），保持画面干净；发车倒数与结算镜头保留真实 HUD，作为「这确实是游戏」的证据。
5. **转场**：段落之间一律 **0.35s 黑场**（硬切到黑、再硬切出），**不用交叉溶解**——溶解会让「该跳到下一站」的界线变模糊。高潮段内部用快切（2s/镜），不加黑场。
6. **字幕版式**：左下角，青色 3px 竖条 + 中文大字（40px）+ 英文小字（18px，字距拉开），淡入 0.25s、停留、淡出 0.30s；位置避开车辆与画面主体。
7. **片头/片尾 LOGO**：为宣传片单独制作的动效（左对齐 + 青色竖条展开 + `APEX VELOCITY` / `极速巅峰` / 卖点行），**不使用游戏开机动画**。
8. **音乐**：`apex.ogg`（APEX ANTHEM，100 BPM，CINEMATIC ELECTRO）铺 00:00–00:57；`neon.ogg`（NEON RUNNER，118 BPM，SYNTHWAVE）接 00:57–01:24，在「霓虹都市」段起点切换，1s 交叉淡化。音量统一 −18 LUFS 左右，片尾 1.2s 淡出。

## 五、执行与验收

**拍摄**：按分镜逐条跑 Godot Movie Maker（`--write-movie` + `--fixed-fps 30` + `--quit-after`），
每条输出一段 AVI；素材放 `trailer/shots/`，命名 `S06_coast_lead.avi` 这样与分镜号对应。
`--trailer-nogrid` 跳过倒数让第一帧即行驶；`--shot-dist` 定位最佳赛段；`--shot-speed` 固定巡航速度。

**剪辑**：按时间码裁切每段 → 统一 1920×1080 / 30fps → 叠字幕层 → 插黑场 → 拼接 → 混音 → 输出 H.264。

**验收清单**：

- [x] 抽帧检查：21 个镜头的顺序与分镜表完全一致，没有时间倒流
- [x] 每个赛道镜头里都能看到车，且车与景观同框（不允许空赛道巡礼）
- [x] 段落之间是黑场（0.4s），高潮段内部是快切，全片无交叉溶解
- [x] 片头片尾是专用 LOGO 动效，没有游戏开机动画
- [x] 画面为当前 Godot 版：真实树/建筑、PBR 路面、紧凑仪表卡、正确天空
- [x] 字幕不遮挡主体，赛道名与英文名拼写与 `data/tracks.json` 一致
- [x] 总时长 84.47s，1920×1080 / 30fps / H.264+AAC，音画同步，片尾淡出干净

**实测**：`apex.ogg` → `neon.ogg` 在 57.2s（霓虹都市段起点）1s 交叉淡化；
成片音量 mean −19.0 dB / peak −1.5 dB；26 段原始 AVI 素材全部由游戏内
Movie Maker 固定 30fps 录制，无旧版网页素材、无 AI 生成画面。

## 七、为拍片对工程做的改动（不影响正常游戏）

`scripts/core/main.gd` 新增一组**仅在 `--shot` 拍片进程生效**的参数与机位：

| 参数 | 作用 |
| --- | --- |
| `--movie-dir=` / `--movie-skip=` | 备用 JPEG 逐帧输出通道（最终采用引擎级 AVI，未启用） |
| `--trailer-shot=hero\|lead\|side\|aerial\|chase\|wheel\|cockpit` | 每帧按车所在赛道坐标重摆电影机位 |
| `--trailer-hud=0\|1` | 隐藏 / 显示比赛 HUD |
| `--trailer-nogrid` | 跳过 3-2-1 倒数，第一帧即行驶状态 |

实际录制使用 **Godot 4 内建 Movie Maker**（`--write-movie` + `--fixed-fps 30`
+ `--quit-after N`）：引擎强制固定时间步，画面运动按真实速度推进，避免
「逐帧读回 GPU 太慢 → 播放变快进」的问题；输出 AVI(MJPEG) 再统一剪辑。
正常启动游戏不会走任何拍片分支，也未改动物理、UI、比赛逻辑。

## 六、审片定稿记录（拍摄后的取舍）

分镜表给的是**意图**，实际选段以逐帧审片结果为准。8 条赛道各拍了「主用机位 + 备选赛段」两条，逐张比较后定稿：

| 站 | 定稿素材 | 机位 / 赛段 | 取舍原因 |
| --- | --- | --- | --- |
| 1 翡翠海岸 | `A06_coast_alt` | hero / 1000m | 主用 `lead` 里车太远太小，备选车与碧海同框更清楚 |
| 2 雪山隘口 | `A07_alpine_alt` | hero / 900m + 轻推近 | 原 `aerial` 俯瞰偏暗、主体过弱 |
| 3 天际环城 | `A08_skyline_alt` | hero / 1100m | 主用 `side` 车被楼影吞掉，备选黄昏逆光层次好 |
| 4 落日港湾 | `A09_harbor_alt` | hero / 1000m + 轻推近 | 主用 `lead` 车几乎不可见，备选金色逆光完整 |
| 5 赤岩峡谷 | `S10_canyon` | **chase / 900m** | 主用车尾 + 赤色岩壁 + 扬尘，保留作为机位变化 |
| 6 熔岩盆地 | `S11_magma` | **hero / 820m** | 主用火山红天与车身反光是全片最强画面，保留 |
| 7 冰川湖环道 | `A12_glacier_alt` | hero / 1100m + 轻推近 | 原 `aerial` 星空意境好但车太小，备选兼顾两者 |
| 8 霓虹都市 | `A13_city_alt` | hero / 1100m | 主用 `lead` 过暗，备选雨夜霓虹下车可辨 |

**两处逻辑修正**：

1. **收尾改到夜城**：初版收尾用 `skyline`（黄昏），成片自检发现光线从「霓虹雨夜」倒退回黄昏，破坏了全片明→暗的时间线。改拍 `city` 夜景后，霓虹都市 → 极限快切 → 夜城最后一程 → 结算的光线连续。同时隐藏该段 HUD：游戏短镜头里 HUD 显示的是「第 1 圈刚起步」，与紧随的 RACE FINISH 结算相矛盾；完赛信息统一交给结算画面，避免自相矛盾。
2. **座驾展示前置**：旧片把车库放在开赛之后，本版放在发车之前，全片无时间倒流。

**机位雷同的处理**：定稿以低侧后 `hero` 为主保证「车与景观同框」，穿插 `chase`，并对第 2/4/7 站做 1.08–1.10 倍的轻微数字重构图，使八段在统一风格下仍有构图差异。

**成片**：`trailer/极速巅峰_宣传片_2026.mp4`（84.47s / 1920×1080 / 30fps / H.264 + AAC）。
**可复现**：`trailer/capture.py` 拍素材 → `trailer/edit.py` 剪成片。旧片 `极速巅峰_宣传片.mp4`（80s，旧 WebGL 画面）已于 2026-11-08 清理删除，不再随项目分发。
