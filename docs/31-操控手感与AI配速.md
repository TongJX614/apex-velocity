# 31 · 操控手感：速度敏感转向 + 加速体感 + AI 配速

> 2026-11-04 · 用户：低速/高速转弯角度要不一样（只针对键盘）；30 和 100+ 加速体感要区分；
> 陪跑 AI 起步不要那么快，速度要跟着玩家走。

---

## 一、键盘转向：低速灵活、高速变「重」

之前 `yaw_rate = steer * 2.2 * spd_norm * (1 - 0.34*speed01)`：
速度超过约 50km/h 后 `spd_norm` 封顶，转向手感几乎不随速度变化。

现在：

```gdscript
var speed01 := clampf(speed_abs / max_speed, 0.0, 1.0)
var steer_authority := 1.12 - 0.72 * pow(speed01, 0.85)
var yaw_rate := steer * 2.35 * spd_norm * steer_authority * (1.32 if handbrake else 1.0)
```

| 车速 | 转向权重 |
| --- | --- |
| 30 km/h | ~1.09 |
| 100 km/h | ~0.89 |
| 180 km/h | ~0.67 |
| 280 km/h | ~0.42 |

- 低速打满方向转弯灵活；高速同样打满，前轮转角被压缩 60%，转向半径明显更大；
- 只改键盘手感（模拟量一样走同一公式），手柄不用管。

## 二、加速/高速体感

- 追尾相机 FOV：60° → 高速 +22°（原来只 +10°），加速时视野快速拉开；
- 相机随速度**后拉 1.6m、升高 0.35m**，高速更有贴地飞驰感；
- 动态模糊改强：`amount = (speed/300)^0.85 * 1.15`，中速就能感觉到；
- 结果：30km/h 巡航和 200km/h 冲刺在画面/FOV/模糊上区别明显。

## 三、陪跑 AI 配速

之前 AI 从 0 直接 damp 到 72–76 m/s（约 260km/h），起步瞬间就到 200+，比玩家快太多。

现在：

1. **起步受加速度限制**：`accel_rate = 12 * (1 - 0.42*speed/base)`，大约和玩家车同级别，
   不再绿灯瞬间 200km/h；
2. **配速跟随玩家**：`pace_ref = clamp(玩家平滑速度 * 1.02, base*0.90, base*1.15)`
   - 玩家跑得快 → AI 跟着快；
   - 玩家跑得慢 → AI 减速到 base 的 90%，不再甩开；
3. 弯道性能惩罚从 `0.40` 抬到 `0.55` 下限，AI 弯速更合理。

验证模拟（玩家自动驾驶 2:58.5 完赛）：最快 AI M. OKADA **3:00.9** 完赛，
差距约 2.4 秒；其余 AI 也保持在同圈竞争区间。
