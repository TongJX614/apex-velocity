## 一、AI 车手分化（`scripts/cars/ai_car.gd`）

开赛后 AI 统一单列「火车队」的根因：配速偏移 `pace_bias` 从未被赋值。本轮按 `skill` 派生完整车手风格：

| 参数 | 来源 | 作用 |
| --- | --- | --- |
| `pace_bias` | `lerpf(-0.10, 0.10, skill01)` | 配速上下 10% 分化 |
| `corner_conf` | 0.72~1.06 | 弯道减速幅度差异 |
| `top_push` | 0.94~1.06 | 直道尾速 / 起步加速度 |
| `lane_pref` | 0~1 | 车线横向位置（0.2+0.28·lane_pref·half_width） |
| `aggression` | 0~1 | 跟车时允许的超速上限 |

- 配速：`pace_ref = clampf(pace·(1.02+pace_bias), base·0.72, base·1.18)`，再乘 `top_push`；
- 弯道限速：`1.0 - curvature·38.0·corner_conf`；
- 跟车上限：`pace·(1.16+0.10·aggression)+1.2`；
- 橡皮筋窗口 ±4% → **±8%**（`gap·0.0007`，clamp 0.92~1.08），玩家慢 AI 让、玩家快 AI 追。

`data/ai.json` 三位车手 baseSpeed 76.5 / 73.6 / 70.8，配合 style 分化后起步即自然拉开梯队。

## 二、物理分车差异化（`scripts/cars/car.gd`）

`_wheelspin_penalty()` 追加扭矩负载项：

```gdscript
var torque_load := (torque_nm * 9.55) / maxf(weight_kg, 800.0)
base *= clampf(0.72 + torque_load * 0.10, 0.72, 1.42)
```

大扭矩/轻车身起步打滑惩罚小（0-100 标定二分自动补偿总加速），重车/小扭矩起步更肉——只改「起步性格」，极速仍由数据表决定。

### 根因与修法（按发现顺序）

1. **`CityNeonPanels` 等经 `_prop_mm_custom` 摆放未过滤** → 该函数接入 `_keepout_keep_idx`；同时把 keepout 过滤改为「保留索引」方案，`_mk_multimesh`/`_mk_multimesh_custom` 的颜色/自定义数据平行数组同步对位（原先直接删 xform 会错位）。
2. **城市楼横向半宽用错维度**：楼体 yaw 对齐赛道切线，局部 Z(=d) 沿路、局部 X(=w) 横跨路，原公式 `lateral = half + d·0.5 + gap` 在大 w 小 d 时楼侧面最多内侵 1m → 改为 `half + w·0.5 + gap`。
3. **赛道闭环折返互压**：赛道是环，折返段贴得很近——建筑/树相对「自己那段」合法，却探进「另一段」。审计加 top-offenders + origin 实测定位后：
   - `VenueKit.distance_to_track` 从「隔样本取最近点（step=2，误差 ~2m）」改为**整环逐段点到线段精确距离**（仅加载期调用，无运行时开销）；
   - `_city_block` 新增跨段净空：`distance_to_track(pos) ≥ 裙楼半对角线 + half + 0.6`（与审计同标准：任何地面顶点距路缘 ≥0.5m）。
4. **树冠延伸超 AABB**：实测渲染顶点延伸可达 `size()` 包围盒半对角线的 **1.5~1.9 倍**（GLB 嵌套中间节点变换、AABB 精度）。
   - `size()` 改用 `_rel_transform(mi, tpl)` 全相对变换；
   - `RealAssetKit` 新增 `true_radius(asset)`：在 `surfaces()` 里对每个 surface 顶点抽样、按 rel 变换后的模板空间水平半径取最大值——**从渲染几何本身测半径**；
   - `_scatter` 净空与 `place_chunked` 禁入区半径全部改用 `true_radius × 实例缩放`，数学上保证顶点不越界。
5. **审计高度感知**：天桥/高架/高空楼体悬挑是故意跨在路上的，纯水平距离会误报 → 只统计「低于路面 +1.0m」的顶点（真压路），并放宽树冠悬挑至 half+1.5m。
