# 55 · 车辆碰撞：修掉「粘上碰」

> 2026-11-06 · 用户：「现在碰撞有点太……了，哪有车碰撞粘上碰啊。」

## 一、原因

v0.52 把车-车碰撞从固定圆改成按 manifest 车宽/车长的 OBB 后，位置分离是对的，但解算只有：
「位置各让一半 + 相对速度 > 0.8m/s 才给冲量」。于是：

- 两车低速/并排接触时，位置每帧挪一点点，速度完全不变 → 看起来**贴在一起滑行**；
- AI 被护栏/赛道边界夹住时（`ai.offset` clamp 到 ±(half_width-1.4)），它「让」不出去的那一半
  没有补偿给玩家 → 两车顶死在边线上，**越贴越紧**；
- 每帧反复重叠→每帧重新判碰，没有分离速度，形成「磁性」接触。

## 二、修法（`main.gd :: _resolve_car_contacts`，第二版）

第一版修完还有两个问题被用户抓到：**低速还有粘感**、**碰撞瞬间车会「闪现到前面」**。第二版：

1. **位置修正常量限幅**：每帧最多把两车各推开 **0.12m**（不再按重叠深度一次性补），
   AI 被护栏夹住时只把少量余量补给玩家 → 不会再出现「瞬移/闪现到前方」；
2. **接触分离速度**：目标分离速度 `max(1.0, 接近速度×0.35)`，单帧速度修正上限 2.5m/s，
   玩家 70% / AI 30% — 低速轻碰也有约 1m/s 的轻微弹开，高速约 35% 反弹，不会弹球；
3. 撞击音效/镜头震动判定改为法线接近速度 < −1.2m/s；
4. 修正后 verify 的强制重叠测试仍 PASS，并新增「防粘/防闪现」断言：
   接触瞬间单帧位移 0.12m（上限 0.40m），反复解算后相对法向速度 +1.00（已分离）。

## 三、验证

- `--verify` M3 强制重叠测试：6 次解算后分离距离 **1.95m → 2.94m**（不再停在刚好贴住的位置）；
- `--editor --quit` 0 SCRIPT ERROR；`--verify` PASS；`--race-test` 正常；
- 现在低速蹭到 AI 会轻轻弹开；高速追尾会把 AI 顶走、自己减速；并排接触不会锁死。

## 四、可继续调

`main.gd :: _resolve_car_contacts` 里：`bias`（分离速度 0.7~2.0）、速度分配 `0.62/0.38`、冲量上限 `6.0`、
位置补偿上限 `depth*1.1`。觉得弹得太开就调小 bias / 分配比例；觉得还粘就调大。
