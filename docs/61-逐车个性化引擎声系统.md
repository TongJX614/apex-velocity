> 编号说明：本文内容成稿早于 `60-开放世界过渡与实体碰撞.md`，原与 `59-无界大陆_开放世界.md` 撞号，

>
> 本文记录「APEX VELOCITY · 极速巅峰」引擎声系统的重写：物理建模合成、逐车档案、
> 真实录音质感层、档位/断油行为，以及配套的客观测量工具链。

## 1. 为什么重写

用户反馈了三个具体问题：

| 反馈 | 根因 |
|---|---|
| 「燃油车被配了电车声音」 | 旧版只按 `engineProfile` 粗分类分派音色，油车和电车共用一套谐波堆栈 |
| 「电机啸叫太尖锐、听着很不舒服」 | EV 叠加了 6 阶纯正弦谐波，基频推到 2.6kHz 后谐波直达 15.5kHz |
| 「V6、V8、V4 声音应该不一样」 | 旧版基频与真实转速完全脱钩，所有缸型的基频几乎相同 |

第三个问题最隐蔽：旧版有一张"基频表"，但它和转速无关，所以听起来全是同一台车。

## 2. 物理建模：基频来自点火频率

四冲程发动机每转点火 `缸数/2` 次，所以点火基频是：

```
f_fire = rpm / 60 × (缸数 / 2)
```

| 缸型 | 每转点火 | 3000rpm | 6000rpm |
|---|---|---|---|
| V8 | 4 | 200 Hz | 400 Hz |
| V6 | 3 | 150 Hz | 300 Hz |
| I4 | 2 | 100 Hz | 200 Hz |
| I3 | 1.5 | 75 Hz | 150 Hz |

这是 V6/V8/I4/I3 听感差异的**物理来源**，也是整套系统的地基。

### 缸体谐波特征

| 缸型 | 特征 | 实现 |
|---|---|---|
| V8 十字平面 | 4 阶谐波突出，怠速有 "burble" | `lope=0.34` 半频 AM |
| V8 平置 | 偶次阶更均匀 | `v8_flat` 权重表 |
| I6 | 2、3 阶突出 | `i6` 权重表 |
| I4 | 谐波分布较均匀 | `i4` 权重表 |
| I3 | 奇数阶 / 半阶突出（1.5 次点火） | `lope=0.40` |

实测（`tools/analyze_engine_spectrum.py`，独立于 manifest 的曲轴阶次口径）：

```
V8 主峰在 4.0x 曲轴转速 (51.1%)   H4/H1 = 0.331 > H2/H1 = 0.294
V6 主峰在 3.0x 曲轴转速 (53.0%)   H2/H1 = 0.317 > H4/H1 = 0.095
I4 主峰在 2.0x 曲轴转速 (44.9%)
I3 主峰在 1.5x 曲轴转速 (50.8%)   半阶/整阶 = 3.14（次高缸型 0.00）
```

### 每台车用自己的红线（而不是写死的 0.99）

归一化转速 `0~1` 是全局刻度，但每台车的红线位置不同（`redlineNorm` 0.92~1.0）。
若把"红区"档写成固定 `rpm = 0.99`：

- 红线 0.94 的车，0.99 已经**冲过红线**（引擎会自动进入断油状态）
- 红线 1.0 的车，0.99 还差一截

同一个数字对 45 台车是 45 种含义。改成 `rpm = redlineNorm` 之后，"红区"才是名副其实的红区，
而且引擎的兜底推断阈值与档案红线严格对齐。

## 3. 架构

```
data/engine_sounds.json      45 台车的逐车档案（由 tools/build_engine_sounds.py 生成）
        ↓
scripts/core/engine_audio.gd
  ├─ 谐波骨架（波表合成）     精确控制音高与音色，6 转速组 × 4 档位交叉淡化
  ├─ 真实录音燃烧质感层        assets/audio/engine/*.ogg，只贡献宽带粗糙感
  ├─ 涡轮哨声 / 泄压阀         随 boost 建立，频率随轴速上扬
  ├─ 断油（fuel cut）          升余弦门 + 机械哒哒声
  └─ EV 电机层                 逆变器基频 + 微量谐波 + 齿轮啸叫 + NVH
```

### 波表合成（性能）

旧版每采样点累加 16 阶正弦（约 70 万次 sin/秒）。现在预生成 2048 点的单周期波表，
运行时只做一次查表 + 线性插值，**CPU 相比旧版不升反降**。

阶次上限按**绝对频率**裁剪而非固定 16 阶：真实排气能量在 3kHz 以上迅速衰减，
固定 16 阶会让 V8 在红线的谐波冲到 8kHz 以上（且混叠）。裁剪上限：

| 档位 | 频谱上限 |
|---|---|
| idle | 2600 Hz |
| cruise | 3400 Hz |
| pull | 4200 Hz |
| redline | 4800 Hz |

最低保留阶次随点火频率自适应（`ceil(1200 / fire_hz)`，钳在 4~10 阶），
否则 I3/I4 这类低点火频率的缸型只剩 4 阶谐波，缸型特征会被抹平。

### 档位划分

| 档位 | 归一化转速区间 | 音色目标 |
|---|---|---|
| idle | 0 ~ 0.16 | 低频 lope 明显、排气有点火不齐的颗粒感 |
| cruise | 0.16 ~ 0.55 | 谐波完整、涡轮开始建立 |
| pull | 0.55 ~ 0.92 | 高频占比抬升、涡轮哨声上扬、排气变亮 |
| redline | 0.92 ~ 1.0 | 谐波最强、叠加断油顿挫与回火 |

实测四档质心**全部单调上升**（45/45 台车），跨度中位 1286 Hz。

## 4. EV 电机

旧版：`140→2590 Hz` 的纯正弦 + 6 阶谐波（最高约 15.5 kHz）——这正是刺耳啸叫的来源。

新版按车型分档封顶基频：

| 档位 | 电机基频上限 | 适用 |
|---|---|---|
| city | 900 Hz | 城市代步、家用电车 |
| mainstream | 1450 Hz | 主流纯电 |
| performance | 1950 Hz | 性能纯电 |
| hyper | 2250 Hz | 高性能纯电、超跑 |

谐波只保留 2 阶（0.055~0.115）与 3 阶（0.022~0.044）的极小量，
另加独立的齿轮啸叫（700→2600 Hz，量级 ×0.55）与低频 NVH 体量。

**实测**：EV 的 >6kHz 能量占比中位数 0.0001%，最大 0.3326%（超跑红区，来自 2203 Hz
基频的 3 阶谐波 ≈6610 Hz，是逆变器推到高基频的必然结果，不是啸叫）。

## 5. 混动：双层声场

混动车是**两层**叠加：

1. 内燃机点火声（`_fill_ice`）
2. 电驱层：程序化合成的逆变器上扬 + NVH（低速电机主导，高速内燃机接管）

早期版本只加了真实电机录音当质感层，听起来是"燃油车 + 一层模糊噪声"。
现在真实录音只贡献宽带粗糙感，音高与时序由程序化层控制。

### 电驱层必须让内燃机当主角

第一版的电机音量公式是 `ev_assist × 车速系数 × (0.55 + 油门 × 0.45)`——
即使完全不踩油门，电机仍有 55% 的音量。实测怠速时**电驱层占了整台车总能量的 78%**，
V8 的怠速"突突"声被压到听不见，听起来就是"燃油车被配了电车声音"
（用户明确抱怨过这一点）。

改成 `ev_assist × 车速系数 × (0.15 + 油门 × 0.85)`：电机只在真正出力时才响。

| 档位 | 电机层能量占比（实测，6 台混动车） |
|---|---|
| idle | 5.1% ~ 13.6% |
| cruise | 11.7% ~ 25.9% |
| pull | 11.7% ~ 24.7% |
| redline | 15.1% ~ 30.1% |

怠速只剩极轻的电流声（纯内燃机），大油门时电机才明显介入 —— 符合真实混动的行为。

### 分层验证：完整混音 − ICE 单层 = 纯电驱层

电驱层在 `_fill_ice` 末尾是**纯叠加**的（`m_amp = ev_assist × …`，`ev_assist = 0` 时整层消失），
审计工具给同一台车同一档位渲染两份样本并固定随机种子（机械噪声轨迹完全一致），
因此差分是精确的，残差里只剩下电机。

| 车型 | 档位 | 期望电机频率 | 实测残差主峰 | 误差 | ICE 基频保留 |
|---|---|---|---|---|---|
| bmw_i8 | idle | 169.2 Hz | 169.2 Hz | −0.03% | 100.0% |
| bmw_i8 | cruise | 911.6 Hz | 911.7 Hz | +0.01% | 100.0% |
| bmw_m5_sedan | redline | 1911.7 Hz | 1911.8 Hz | +0.00% | 100.1% |
| bmw_csl_hommage | pull | 1188.9 Hz | 1188.9 Hz | +0.00% | 100.0% |

残差主峰两侧还能看到 1/2 频（NVH）与 2 次谐波，符合电驱层的合成结构。
全部 30 个混动样本的频率误差 ≤ 0.027%，ICE 基频保留 ≥ 99.2%。

> 顺带修掉了一个测量缺陷：混动是**双声源**，逆变器主音可能比点火基频还强
> （bmw_i8 巡航：逆变器 911.7 Hz 幅度 297 vs 点火基频 86.0 Hz 幅度 280）。
> "取最强峰"的基频检测器会锁到电机音上，报出 959% 的假误差。
> 现在点火基频一律从 **ICE 单层**渲染测，完整混音只用来验证电驱层。

## 6. 断油（fuel cut）

不是简单的正弦门限，而是「点火断续 + 哒哒机械声」：

- 断续频率 = 点火频率的一半（8~60 Hz），转速越高断续越细密
- **门限必须是平滑的（升余弦）**。方波的陡峭边沿在频谱上等于给每个谐波加一对
  宽带边带，早期实测 ICE 断油 >6kHz 能量占比因此高达 **2.09%**（是 EV 最差值的 6.3 倍），
  听着像"金属啸叫"而不是"断油顿挫"。改成升余弦门后降到 **0.15%**（降 14 倍）；
  现在断油档实测边带 ≤ **0.1498%**（`bmw_218i`），仍低于 EV 最差值。

### 断油状态必须由车辆传入

`car.gd` 里已经算好了 `limiter_active` / `fuel_cut`，但旧链路
`update_engine(rpm, throttle, speed01, gear)` 没把它传下去，引擎声只能自己猜。

两个由此暴露的问题：

1. **旧猜测阈值 0.985 是错的**：游戏里每台车红线归一化值是 0.92~1.0，
   用固定 0.985 意味着 **33/45 台车永远触发不了断油声**。
   → 档案新增 `redlineNorm`（从 `data/cars.json` 读取），断油阈值按各车自己的红线算。
2. **真实转速换算的基准也是错的**：原来用固定 `0.9` 作红线基准，
   红线 0.92 的车永远到不了自己的红线，红线 1.0 的车又提前很久就到顶。
   → 改用 `redline_norm`。修正后基频测量误差从 2.2~4.2% 降到 **0.001~0.24%**。

### 三态参数（避免"幽灵断油"）

```gdscript
func update_sound(rpm, throttle, speed01, gear, fuel_cut: int = -1)
```

| fuel_cut | 含义 |
|---|---|
| `1` | 车辆确实在断油（权威，来自 `car.limiter_active`） |
| `0` | 车辆明确没有断油（权威，不要自己推断） |
| `-1` | 调用方未提供（仅调试/审计用），此时才按红线推断 |

早先用 bool 两态时，`false` 与"未提供"无法区分 —— 车辆还没断油但转速过线时，
引擎会自行断油，实测 **33/45 台车**出现"幽灵断油"，每台 20~58 帧。
三态方案下不一致帧 **27→0**。

### 自动挡的断油：已修复（原来一次都触发不到）

第一版断油阈值是 `redline × 1.002`，而：

- 顶挡的极速占比 `GEAR_TOPS` 末位 = 1.0 → 车跑到极速时**正好是红线**
- 车速被 `_speed_cap()` 硬钳在 `max_speed`，永远超不过去
- 默认是**自动挡**（`var manual := false`）

三个条件叠在一起，`rpm > redline × 1.002` 在自动挡下**永远不成立**。
实测（`tools/limiter_probe.gd`，直接驱动真实的 `car.gd`）：

| 阈值 | 自动挡能触发断油 | 手动挡能触发断油 |
|---|---|---|
| `redline × 1.002`（旧） | **0 / 33** | 33 / 33 |
| `redline × 0.998`（新） | **33 / 33** | 33 / 33 |

真实断油限速器就是在红线处切断点火，所以阈值必须 ≤ 红线。
`0.998` 与升挡阈值 `0.985` 之间留出的滞回带，让车在极速附近"顶着限速器弹跳"
（实测断油帧 187~630，最长连续段 19~25 帧 ≈ 0.3~0.4 秒的连续顿挫），
终速保持在极速的 99.84%~100% —— 听得见，但不会把车按住。

`engine_audio.gd` 兜底推断阈值同步改为 `redline_norm × 0.998`，
避免出现"车还在给油、引擎却已经熄火"的错位。

### 断油声长什么样（客观口径）

审计工具给每个档位渲染 5 个场景，`fuelcut` 档与红区档**同转速同油门**，只差点火是否被切断：

| 车型 | 红区 RMS | 断油 RMS | 比值 | 红区 >6k% | 断油 >6k% |
|---|---|---|---|---|---|
| bmw_m3_e46_gtr | 0.0559 | 0.0359 | 64% | 0.0078% | 0.0272% |
| bmw_m4_g82 | 0.0425 | 0.0272 | 64% | 0.0237% | 0.0600% |
| bmw_218i | 0.0208 | 0.0135 | 65% | 0.0616% | 0.1498% |
| bmw_i8 | 0.0461 | 0.0327 | 71% | 0.0203% | 0.0422% |

断油把燃烧能量掐掉约 **36%**（听感是"点不着火的顿挫"而不是连续轰鸣），
断续门带来的边带占比 ≤ 0.15%，**低于 EV 最差值 0.33%** —— 是"顿挫"不是"金属啸叫"。

## 7. 真实录音质感层

`assets/audio/engine/` 下的 CC0 素材作为**燃烧质感层**叠加。

### 选材原则（实测数据）

质感层**绝不能**在 40~90 Hz 有强峰 —— 那是点火基频区，两层都在那里发力就会
互相打架，听起来像"两台引擎"。

| 素材 | 40~90Hz 占比 | 谱平坦度 | 结论 |
|---|---|---|---|
| `motor_seamless_13.ogg` | **0.4%** | 高 | V8 用（厚实排气体量） |
| `motor_seamless_12.ogg` | **0.6%** | 高 | I6 用 |
| `motor_seamless_10.ogg` | **1.1%** | 高 | I4 用 |
| `motor_seamless_02.ogg` | 2.9% | 高 | I3 用（粗糙度最高） |
| `race_loop_p1.ogg` | **43.5%** | 极低 | **排除**（近乎纯音，83~95% 能量在基频） |
| `ev_motor_fan.ogg` | 3.3% | 中 | EV 电机层 |

### 授权

全部选用的素材均为 **CC0**（无需署名）。完整清单见
`assets/audio/engine/README.md`（107 条素材，逐条标注协议、来源、作者、原始 URL）。
该目录另有 53 条 CC-BY / CC-BY-SA 素材目前未被引擎声引用；
若将来使用，必须在游戏内 Credits 逐条署名，CC-BY-SA 还有传染性限制。

## 8. 测量工具链

> **教训**：早期版本在 GDScript 里用 Goertzel 幅度加权法测频谱质心，
> 用已知信号（100 Hz + 0.2×3kHz，理论质心 583.3 Hz）标定时测出 **1931 Hz**，
> 偏差超 3 倍。那一轮"高音刺耳"的结论、以及基于它的三处修改全是错的。
> 频谱分析因此改用 numpy FFT（功率谱加权 + Hann 窗），并内置标定自检。

```bash
# 1. 渲染 45 台车 × 5 档位 + 30 个混动 ICE 单层 = 255 个样本
Godot --headless --path . --script res://tools/audio_audit.gd
#    → /tmp/engine_audio_samples/<scene>/<car_id>.wav
#    → /tmp/engine_audio_manifest.json

# 2. 频谱分析
python3 tools/analyze_engine_spectrum.py
#    → /tmp/engine_audio_spectrum_report.txt

# 3. 断油可达性（必须以场景方式跑，--script 模式不注册 autoload）
Godot --headless --path . res://tools/limiter_probe.tscn
#    → /tmp/limiter_probe.json
```

### 两套口径

混动车必须分两层测，否则会得出假的结论：

| 口径 | 样本 | 回答的问题 |
|---|---|---|
| **缸型物理** | 混动取 ICE 单层，纯 ICE 取完整混音 | 这台车是几缸？点火基频多少？ |
| **玩家听到** | 全部取完整混音（含电驱层 / EV 层） | 音色刺不刺耳？四个档位有没有区分度？ |

断油档（`fuelcut`）单独统计，不混进四档口径。

### 口径限制

- 报告只覆盖**程序化合成**部分。真实录音质感层走独立 `AudioStreamPlayer` 通道，
  没有混进 WAV，所以真实听感的高频会略高于报告数字，0.5% 这条线要留余量。
- V8 红区的点火基频最高到 560 Hz，已顶到 20~600 Hz 的常规搜索窗上界，
  分析器把上界放宽到 1300 Hz。
- I3 怠速基频仅 21 Hz（其 3 阶谐波 63 Hz 幅度更高），分析器内置「次谐波回退」才能量到真基频。
